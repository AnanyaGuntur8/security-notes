Starting with the Linux command line

OverTheWire Bandit starts with an SSH login. The first few exercises are a chance to practice navigating and reading files in a terminal.

Read files by name

Use pwd to see your working directory and ls -la to list entries, including dotfiles. Quote filenames with spaces so the shell passes each name as a single argument.

pwd
ls -la
cat -- "practice notes.txt"

The -- marks the end of options. A relative path such as ./-draft also works for a filename that starts with a dash.
